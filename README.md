# Más Que Mario

Jogo de plataforma 2D feito em **Godot 4.6** como projeto de estudo do curso de Ciência da Computação (Unifor).

## Conteúdo
- 4 fases
- Menu principal e tela de game over
- Inimigos com comportamentos diferentes
- Power-up de bola de fogo
- Sistema de pontuação

## Como rodar
1. Instale o [Godot 4.6](https://godotengine.org/download)
2. No gerenciador de projetos, clique em **Importar** e selecione o `project.godot`
3. Pressione **F5**
